# GDG on Campus – RIT Hassan 🚀

Official website for **Google Developer Groups (GDG) on Campus** at **Rajeev Institute of Technology, Hassan**.

🌐 **Live Website:** [https://preethamcm18.github.io/GDG-WEBSITE/](https://preethamcm18.github.io/GDG-WEBSITE/)

---

## 💻 Run Locally on Your Computer (Localhost)

You can run and preview this website locally using the included Node.js server:

### 1. Start the Local Server
Open your terminal in the project directory and run:

```bash
node serve.js
```

### 2. Open in Browser
Once running, open the link in your web browser:

👉 **[http://localhost:3000](http://localhost:3000)**
